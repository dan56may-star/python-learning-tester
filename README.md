Python Tester

Це мій перший серйозний проєкт на Python, написаний під час навчання!

Що вміє програма:
* **Анкетування:** Збір даних про користувача (ім'я, вік, місто).
* **Інтерактивне меню:** Вибір дій за допомогою циклів `while` та умов `if/elif`.
* **Система тестів:** Перевірка знань базових команд Python (`input`, `print`).
* **Логіка балів:** Програма рахує правильні відповіді та зберігає результат у профілі.
* **Ефекти:** Використання бібліотеки `time` для затримок (імітація завантаження).

Технології:
* Python 3.10+
* Модуль `time`
* Функції (`def`) та глобальні змінні.
